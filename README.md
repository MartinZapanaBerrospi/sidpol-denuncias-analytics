# SIDPOL Denuncias Analytics

> **En construcción.** El proyecto avanza por fases; este README se completa con los hallazgos y
> el enlace al tablero al terminar.

Análisis de las **denuncias policiales del Perú** (7,36 millones entre enero de 2018 y julio de
2026) con **datos abiertos reales** del Ministerio del Interior: qué modalidades cambian, qué
territorios pesan más por habitante y qué distritos se salen de su propia historia. Termina en un
tablero de Power BI para gerencia.
